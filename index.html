🌍 SDG 12: Responsible Consumption and Production

My application aims to reduce household food waste by managing grocery lists efficiently and enabling surplus food donations to the community.

Laboratory Work

Lab 1: UI

Reflection: In this lab, I learned the fundamentals of Jetpack Compose by building basic user interfaces. I experimented with layouts like Column, Row, and Box, and utilized basic composables to structure an app screen effectively.

Lab 2: Interaction

Reflection: This lab introduced me to state management in Compose using remember and mutableStateOf. I learned how to make the UI interactive by handling button clicks and updating the screen dynamically based on user input.

Lab 3: Material Design

Reflection: Here, I explored Material Design 3 guidelines to enhance the visual appeal of my application. I implemented components like Scaffold and TopAppBar, applying consistent color themes to ensure a modern user experience.

Lab 4: Navigation

Reflection: Mastering navigation was the core focus of this lab. I utilized Jetpack Navigation Compose to build a seamless multi-screen experience, passing data and allowing users to transition smoothly between different screens.

Lab 5: Room Database

Reflection: This lab was crucial for understanding data persistence. I successfully integrated Room Database to store application data locally, ensuring that user inputs like grocery items are saved permanently even when the app is closed.

Projects

Project 1: NgamNgam (Local Features)

Problem Statement: Many households struggle with food waste due to over-purchasing and poor grocery planning. NgamNgam was created to help users calculate precise ingredient portions and manage their shopping lists effectively.

Lessons Learned: I learned how to manage complex UI states and implement a multi-screen navigation flow using Jetpack Navigation Compose. Sharing a common ViewModel across different screens was a significant milestone in ensuring data consistency throughout the app.

Project 2: NgamNgam (Cloud & Sensors)

Problem Statement: Building upon the local grocery list, there was a need to easily add physical items via scanning and share surplus food with the community. Integrating barcode scanning and a cloud-based donation system directly addresses this gap to further promote responsible consumption.

Lessons Learned: This project taught me how to bridge local and cloud data by seamlessly combining Room Database with Firebase Firestore. I also gained practical experience integrating hardware sensors through Google ML Kit for real-time barcode scanning.
